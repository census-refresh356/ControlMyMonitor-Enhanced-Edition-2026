## Frequently Asked Questions

Here are answers to some common queries:

### 1. What monitors are compatible with ControlMyMonitor?
ControlMyMonitor works with most standard monitors connected via HDMI, DisplayPort, VGA, or DVI. It is optimized for Windows 10 and Windows 11, and compatibility may vary with older systems. Always ensure your graphics drivers are up to date for the best results.

### 2. How do I troubleshoot if the application doesn't detect my monitor?
If your monitor isn't detected, try restarting your computer, checking cable connections, and updating your graphics drivers. You can also run the application as administrator or refer to the troubleshooting section in the app for additional help.

### 3. Can I undo changes if something goes wrong?
Yes, ControlMyMonitor includes a profile backup feature. Before making changes, save your current settings to a profile. You can later restore from this backup if needed. Additionally, Windows has built-in options to reset display settings.

### 4. Is administrative permission required to use ControlMyMonitor?
Some advanced features, like modifying system-level display settings, may require administrative privileges. The installer will prompt for elevation during setup, and the app may request it for certain operations.

### 5. Does ControlMyMonitor affect system performance?
ControlMyMonitor is designed to be lightweight and run in the background without significant impact on system resources. It only activates when you adjust settings, and you can close it when not in use to free up memory.
